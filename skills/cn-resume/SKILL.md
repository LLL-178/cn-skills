# 中文简历优化

帮用户把经历改写成能通过 HR 初筛和 ATS 关键词筛选的中文简历。

## 中文简历和国外的差异

国内简历默认**一页**(十年以上经验最多两页),且有一些国外简历模板没有的字段。先按用户阶段定框架:

- **应届/实习**:教育经历放最前(学校、专业、绩点/排名、相关课程),实习和项目其次。
- **社招 ≤5 年**:工作经历在前,教育经历放最后。
- **社招 >5 年**:教育经历放最后且一行带过;重点放在"带过多少人、扛过多大的盘子"。
- 基本信息按行业取舍:国企/银行/体制内要照片、政治面貌、籍贯;互联网/外企只要姓名、电话、邮箱、城市,照片反而不用。

## 工作流程

1. **拿到两样东西**:现有简历(或口述经历)+ 目标岗位 JD。没有 JD 时先问目标岗位,没有 JD 的简历优化是盲改。
2. **从 JD 提取关键词**:硬性技能(技术栈/证书/工具)、行业词、软性要求各列一列,这些词必须自然出现在简历里——ATS 和 HR 的第一轮筛选本质是关键词匹配。
3. **逐条改写经历**,用下面的改写规则。
4. **输出**:Markdown 简历全文 + 逐条改写对照表(让用户看到改了什么、为什么改)。
5. 自检清单过一遍。

## 经历改写规则

每条经历 = 动词开头 + 做了什么 + **量化结果**。衡量标准:这句话换个人也能写,就是废句。

改写示例(改前 → 改后):

- "负责用户增长相关工作" → "搭建小红书获客渠道,3 个月带来 1.2 万注册用户,获客成本从 45 元降到 18 元"
- "参与开发订单系统" → "独立负责订单超时自动取消模块,将客服人工处理量减少 70%"
- "协助团队完成日常运营" → 具体到:运营了什么、规模多大、结果如何

**量化没有精确数字怎么办**:写范围("约 3 万")、写对比("较此前提升约一倍")、写频次("每周处理 50+ 单"),不要编造精确假数字——面试会被拆穿。

## 用词分级(真实但克制)

- 精通:只在能现场手写实现时用。简历上写"精通"面试官就会按专家标准问。
- 熟悉/熟练使用:日常工作主力的技术,默认用这档。
- 了解/接触过:诚实标注,反而显得可信。

职责动词用"负责/独立完成/主导/搭建",避免"参与/协助/了解"堆一屏——全是协助等于没有产出。

## 渠道适配提醒

- **BOSS直聘**:简历第一行和打招呼语决定回复率。打招呼语 = 一句和 JD 强相关的经历 + 一个量化结果,不要用"您好,我对贵司职位很感兴趣"。
- **ATS 机器筛选**:导出 PDF 必须保证文字可复制可搜索(不要纯图片扫描版);不要用花哨的双栏表格模板,解析容易乱序。
- **内推**:帮用户把简历改出 3 个"钩子点"(面试官大概率会追问的亮点),每处准备 1 个可展开的故事。

## 输出格式

1. 逐条改写对照表(原文 → 改后 → 改动理由)
2. 完整 Markdown 简历(可直接粘贴到模板)
3. 针对 JD 预测的 5 个面试追问(基于简历里最可能被挑战的点)

## 自检清单

- [ ] 一页以内(应届)/ 两页以内(10年+)
- [ ] JD 硬性关键词已全部自然出现
- [ ] 每条经历都有量化,且数字经得起面试追问
- [ ] 没有"精通"堆砌,没有整屏"协助/参与"
- [ ] 时间线无空窗漏洞(有空窗期时帮用户准备一句话解释)
- [ ] PDF 可复制、可搜索
