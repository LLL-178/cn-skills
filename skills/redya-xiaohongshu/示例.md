# 小红书图文与实况图·红鸦 AI

## 安装后查看用法

输入：

> 怎么用

此指令直接展示包内帮助，不需要配置 Key。完整帮助如下。

复制下面任意一句到已安装红鸦 Skill 的对话里，把方括号里的内容换成自己的链接或文案。使用自己的照片时，把照片和指令一起发。

| 我想做什么 | 可以直接这样说 |
| --- | --- |
| 普通图文 | 用红鸦写一篇「周末书桌收纳」图文，做 4 页，先给我看标题、正文和每页大纲。 |
| 商品图文 | 用我已建档的「青皮无花果干」做一篇办公室零食图文，卖点按商品档案写，只在最后一页展示包装，直接出图。 |
| 爆文复刻 | 复刻这篇：[粘贴小红书分享口令]。参考原图样式，换成「过了 25 岁想要皮肤好，切记这些」，直接一步出图。 |
| 实况图文 · 用自己的照片 | 用我上传的这几张照片做一篇周末探店实况图文。保留原图，写好标题和正文，直接转实况。 |
| 实况图文 · 用 AI 配图 | 做一篇球鞋开箱实况图文，参考我上传的球鞋图生成实拍风格配图。先给我看大纲。 |
| 敏感词检测 | 用红鸦查一下这段文案：[粘贴文案]。标出命中的词和原因，先给我看修改建议。 |
| 发布已有作品 | 把刚才那篇图文带到小红书发布编辑器，填好标题、正文和图片，我来确认发布。 |

想先修改内容，可以说「先给我看大纲」，看完接一句「第 2 页改成收纳前后对比，其他页按原稿，确认出图」。想直接拿成品，就说「直接出图」或「一步出实况」。

正文
之前夏天想喝冰咖啡，每次用老式冰格都要拧半天，有时候还会撒一冰箱水，弄得台面到处湿漉漉的，后来冰格直接被我闲置了🥲。

最近一直在用这个三合一冰格水杯，说实话比我想象中顺手很多✨。它把做冰、储冰和喝水做在了一起，上面是模具，下面直接连着大容量水杯。

平时切两片柠檬或者薄荷叶丢进去，加满水直接倒扣着塞进冰箱冷冻层，密封挺严实的，目前没遇到过漏水的情况👀。

冻硬之后拿出来，单手对着顶上一按，冰块就哗啦啦全掉到底下杯子里了✅，完全不用费劲拧模具，也不用拿手一块块抠，干净又解压。

直接往杯里倒牛奶或者乌龙茶，插上自带的吸管就能喝，保温保冷时间也够用。杯口配了便携提手，出门散步随手拎着很轻便。材质是抗菌材质，装各种饮品用着比较踏实。

⚠️说一个小细节：按压模具的细小边缘在清洗时需要用细刷顺手带一下，冲干净晾干就不会留味道。总体用下来省掉了很多瓶瓶罐罐，天热喝水确实方便不少。

## 自检

- 查看帮助时展示七条例句和分步提示，无需提供 API Key。
- 用户指定复刻并提供笔记链接时，先用红鸦解析来源，再按复刻模式处理。
- 分步生成时先交付大纲，一步出图时核对返回图片页数。
- 生成使用用户自己的 Key 和积分；通过插件发布时，由用户在目标编辑器确认。
