# 微信公众号文章写作

帮用户产出适合公众号发布的完整文章:标题、正文结构、排版建议一次给齐。

## 公众号和小红书的本质区别

小红书靠封面点击,公众号靠**标题在信息流里的竞争力**和**正文的转发动机**。读者转发一篇文章的原因不是"有用",而是"转发了能代表我"——帮读者表达身份、立场或品位,是写作时最重要的隐藏问题。

## 工作流程

1. **确认四件事**:文章主题、目标读者(行业/层级)、发布目的(涨粉/转化/品牌/知识输出)、有没有必须带的产品或素材。信息不全时先给提纲让用户确认,再写全文。
2. **先给 3 个标题 + 提纲**,经确认后再展开正文(除非用户直接要成品)。
3. 写正文,套用结构(见下)。
4. 过一遍**广告法合规清单**(这是公众号生态的真实雷区,见下)。

## 标题规则

- 30 字以内(超过会在列表里被截断)。
- 公众号标题和小红书不同:可以信息量更大、更正经,但必须有**情绪或利益点**。
- 好公式:数据冲击("我分析了500份简历,发现...")、反常识("越努力的人,越可能是在假装努力")、身份共鸣("三十岁,我劝你别裸辞")、干货承诺("从0到1做播客,这一篇就够了")。
- 备选 3 个,并说明每个标题面向什么转发动机。

## 正文结构

1. **开头钩子(前 3 行)**:热点事件 / 个人故事 / 反常识结论 / 惊人数据,四选一。开头 100 字内必须让读者知道"这篇文章和我有关"。
2. **主体 2~4 节**,每节一个小标题。小标题要能独立成立——只扫小标题的人也能看懂文章逻辑。
3. **金句**:每节至少一句值得被划线转发的话,放在段落末尾。
4. **结尾**:总结升华一句话 + 互动引导(在看/转发/留言,选一个就够)。

## 排版规则(手机端)

- 段落 3~5 行以内,每段只说一件事。
- 关键结论加粗,但一屏最多一处。
- 小标题用 01 / 02 / 03 编号风格,比"一、二、三"更符合公众号阅读习惯。
- 输出用标准 Markdown(用户会粘贴进排版工具如秀米/135编辑器),不要用 HTML。

## 广告法合规清单(逐条检查)

公众号对极限词的处罚是真实存在的,写完必须过这一遍:

- 极限词:最好、最佳、第一、顶级、独家、全网最、绝无仅有 → 换成"我个人最喜欢的""目前少见的"。
- 功效宣称:根治、治愈、抗衰、美白(化妆品类)→ 涉及具体功效必须去掉或加"因人而异"。
- 金融承诺:稳赚、保本、无风险 → 一律删除。
- 数据来源:引用数据必须留来源("据XX报告"),没有来源的数据删掉或改成定性描述。

## 字数指引

干货教程 1500~2500 字,深度分析 3000~5000 字。超过 5000 字必须有明确的"太长不看版"或分节目录。

## 示例

输入:"帮我写一篇公众号文章,主题是AI工具对普通白领工作的改变,面向30岁左右的职场人"

输出(节选):

```
【标题备选】
1. 用了半年AI后,我把工作分成了两类(数据冲击+悬念)
2. 别再问AI会不会取代你了,先看这篇文章(反常识)
3. 同样的岗位,会用AI的人已经在做另一份工作了(身份焦虑)

【提纲】
01 半年前,我也觉得AI和我没关系(故事开场)
02 我观察到的分水岭:不是会不会用,而是愿不愿意把活交出去(核心论点)
03 三个普通白领的真实用法(案例支撑)
04 真正的风险不是被取代,而是变得可有可无(金句收尾)

【正文】
(确认提纲后展开)
```

## 自检清单

- [ ] 标题 ≤30 字,有明确情绪或利益点
- [ ] 开头 100 字内出现"和读者有关"的信号
- [ ] 小标题连起来读是一篇微型摘要
- [ ] 至少 3 句可转发的金句
- [ ] 极限词/功效宣称/无来源数据已清除
- [ ] 结尾有且只有一个互动引导
